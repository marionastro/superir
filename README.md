<b>SuperIR</b> is a powerful tool and system model for Information Retrieval (IR). The main purpose of the application is to satisfy the user's information need, ensuring they get the documents that respond to their request. The application allows for calculating the scores of text documents located in a selected folder, based on the frequency of words specified in a user-defined query. The documents are then listed in order of relevance, from the most relevant (highest score) to the least relevant.

<h1>🎯 Key Features</h1>
<ul>
  <li>
    <b>Folder Selection</b>: The user can select the reference folder containing the files to be examined either by selecting it from the computer or by dragging and dropping it into the interface.
  </li>
  <li>
    <b>Query Processing</b>: The user can define and enter a textual query to be used in the IR algorithm.
  </li>
  <li>
    <b>Choice of IR Algorithm</b>: The application allows the user to establish the IR algorithm to use for calculating the scores. By default, "StandardIR" is used, but it is alternatively possible to select the "TF-IDF" algorithm.
  </li>
  <li>
    <b>Title/Body Weight Balancing</b>: The user can define the percentage weights that the title (considered as the first line of the text document) and the body of the documents have on the final score. Their sum must be equal to 100.
  </li>
  <li>
    <b>Stopwords Filtering</b>: The user can select one or more text files containing stopwords. These irrelevant words are "eliminated" from the vocabularies so they do not influence the scores.
  </li>
  <li>
    <b>In-App Document Viewing</b>: After calculating the scores, it is possible to select a document from the results list to view its content directly in the app.
  </li>
  <li>
    <b>Statistics View</b>: The application shows statistics for the analyzed folder and for the single documents. Folder statistics include the total number of words, average word length, and word frequencies, while document statistics show word counts, word frequencies, and score details.
  </li>
  <li>
    <b>Null Scores Display</b>: By default, the application does not show documents with a score of 0, but the user has the option to show or hide documents with a null score from the results screen.
  </li>
</ul>
<h1>🧠 Algorithms and Math</h1>
<ul>
  <li>
    <b>Standard IR</b>: This algorithm calculates a document's score solely based on the frequency with which the query words appear in it.
  </li>
  <li>
    <b>TF-IDF</b>: If selected, this algorithm calculates the score based on the rarity of the terms, giving greater weight to terms that appear in the document but are generally infrequent among the folder's documents.
  </li>
  <li>
    <b>Cosine Similarity</b>: The system utilizes Cosine Similarity to calculate the similarity between the values generated by the query's vocabulary and those of the document's vocabulary.
  </li>
</ul>
